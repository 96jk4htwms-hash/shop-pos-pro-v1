🛡️ ระบบป้องกันการขาย

🧾 ข้อมูลร้าน (แสดงบนใบเสร็จ)

เชื่อมต่อ Supabase

เข้าสู่ระบบร้านค้า (เจ้าของร้าน)

กรอก 2 ช่องข้างล่างนี้เฉพาะตอน "สมัคร (ครั้งแรก)" เท่านั้น — ใช้ตั้งค่าบัญชีเจ้าของร้านคนแรกของร้าน (PIN นี้จะใช้ล็อกอินหน้าขายด้วย)

📥 ยกยอด & นำเข้าไฟล์ (สินค้า)

นำเข้าสินค้าจากไฟล์ Excel (.xlsx) ที่มีคอลัมน์ ชื่อสินค้า / SKU / ขนาด / หมวดหมู่ / ราคาทุน / ราคาขาย / ยอดยกมา / ไฟล์รูปภาพ — ระบบจะอ่านเฉพาะ ชื่อสินค้า / SKU / ราคาทุน / ราคาขาย / ยอดยกมา โดยอัตโนมัติ ส่วน "หมวดหมู่" และ "ขนาด" เป็นข้อมูลอ้างอิงเท่านั้น (สินค้าทุกชิ้นจะถูกใส่ในหมวด "งานทั่วไป" ก่อนเสมอ ต้องเข้าไปแก้หมวดหมู่ทีละสินค้าที่หน้าคลังสินค้าเองภายหลัง)

🖼️ นำเข้ารูป (ชุด)

จับคู่รูปภาพเข้ากับสินค้าที่นำเข้าไว้แล้ว (จับคู่จาก "ชื่อสินค้า" ให้ตรงกับที่นำเข้าไว้ก่อนหน้านี้) — ต้องเชื่อมต่อ + เข้าสู่ระบบ Supabase ก่อน เพราะรูปจะถูกอัปโหลดขึ้น Supabase Storage โดยตรง (ไฟล์รูปหลายพันไฟล์เก็บเป็น base64 ในเครื่องอย่างเดียวจะทำให้พื้นที่เก็บข้อมูลของเบราว์เซอร์เต็มและแอปพังได้)

🧨 เริ่มต้นระบบใหม่ / ล้างข้อมูล

ใช้เมื่อต้องการล้างข้อมูลทดสอบทิ้งแล้วเริ่มขายจริง, ล้างข้อมูลร้านเดิมทั้งหมด, หรือย้ายไปใช้ฐานข้อมูล Supabase โปรเจกต์ใหม่ — ทุกทางเลือกด้านล่างย้อนกลับไม่ได้
